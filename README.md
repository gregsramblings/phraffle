phraffle
========

[Phraffle.com](https://phraffle.com) — instant raffles using mobile phone numbers as raffle tickets.

It's a slot machine showing the last four digits of a phone number. Spin the
reels, then stop them one at a time to whittle a crowd down to a single winner.

How to run a giveaway
---------------------

- Get the whole room to stand up.
- The reels show the last four digits of a phone number. Everyone stays standing only while the digits match their own.
- Tap the right-hand reel to stop it — about 90% of the room should sit down.
- Tap the next reel to its left. If nobody's left standing, spin it again and retry.
- Last person standing wins.
- In a room of 100, it usually takes 2–4 taps to land on one winner.

Running it
----------

It's a static site — no build step, no dependencies. Open `index.html` in a
browser, or serve the folder with any static server, e.g.:

```
python3 -m http.server 8000   # then visit http://localhost:8000
```

How it works
------------

Each of the four number reels is one tall sprite
(`images/reel_normal_numbers.png`, 86×750px = ten 75px digits). `raffle.js`
animates `background-position` with `requestAnimationFrame`, swapping to a
motion-blur sprite (`reel_blur_numbers.png`) while spinning fast and easing onto
a whole digit when stopped. The `XXX-` prefix is a separate static sprite.

Implemented in vanilla JS — no jQuery, no plugins, no external requests.
Respects `prefers-reduced-motion` and the reels are keyboard-operable.

SEO & assets
------------

The page ships Open Graph + Twitter Card tags, JSON-LD (`WebApplication`) structured
data, a canonical URL, `robots.txt`, and `sitemap.xml`.

- Fonts are self-hosted in `fonts/` — Pacifico for the logo, Nunito (variable) for body text.
- `favicon.svg` is the primary favicon; `favicon.png` is a 64×64 fallback.
- `og-image.png` (1200×630 social card) and `favicon.png` were generated by rendering
  the brand fonts onto a `<canvas>` and exporting the PNG.

History
-------

Originally built in 2012 on jQuery + spritely with an HTML5 AppCache manifest,
TypeKit fonts, and Google Analytics. Modernized in 2026 to a zero-dependency
vanilla rewrite: AppCache, TypeKit, and analytics removed; the logo font
(Pacifico) is now self-hosted; the layout is responsive.

Slot mechanic originally based on code by Saurabh Odhyan
(http://odhyan.com), used under CC BY-SA 3.0.

Blog post describing the app — http://gregsramblings.com/2012/05/13/an-interesting-way-to-handle-event-giveaways-phraffle-com/
